## 🎨 Theme System

The portfolio includes an intelligent theme system:

- **Time-Based Detection**: Automatically switches to dark mode from 6 PM to 6 AM
- **User Preference**: Users can manually toggle the theme
- **Local Storage**: Saves user preference for future visits
- **Smooth Transitions**: All theme changes are animated

### Theme Colors

**Light Theme:**
- Primary: `#2563eb` (Blue)
- Accent: `#f59e0b` (Amber)
- Background: `#f9fafb` (Light Gray)

**Dark Theme:**
- Automatic dark background and text colors
- Same primary accent colors for consistency

## 🔧 Customization

### Change Theme Colors
Edit the CSS variables in `style.css`:
```css
:root {
    --primary-color: #2563eb;
    --secondary-color: #1e40af;
    --accent-color: #f59e0b;
    /* ... more variables ... */
}
```

### Update Profile Picture
Replace `mydp.png` with your own image (keep the same filename).

### Modify Content
Edit the relevant sections in `index.html` to update:
- About section
- Skills
- Experience
- Certifications
- Contact information
